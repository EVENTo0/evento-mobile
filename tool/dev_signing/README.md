# EVENTO development signing identity

The phone-first Android channel uses one persistent development signing identity so each successful `dev-latest` APK can install as an update over the previous EVENTO development build on the designated Android test phone.

This key is development-only and must never be reused for Play Store production signing.

Expected SHA-256 fingerprint:
`BA:C5:A3:17:AC:D9:28:6A:A3:46:26:8D:AF:F0:46:3D:AE:65:39:32:F4:83:84:5E:12:99:55:DE:4D:06:9A:36`
